EASY SEARCH is a personal web project built to make searching the internet simple, colorful, and easy to use.

What is EASY SEARCH?

It is a simple search homepage with a colorful design. DuckDuckGo provides the search results.

02

Why was it created?

This project helps demonstrate how HTML, CSS, and JavaScript can work together to create a useful website.

03

What's next?
